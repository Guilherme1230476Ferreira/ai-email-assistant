# BO-1: Admin Dashboard

## Description
As an administrator, I want a high-level overview of system usage and health so that I can monitor performance at a glance.

## Acceptance Criteria
- [ ] Implement a dashboard home page showing key metrics (Total Users, Total Emails, Tokens Saved).
- [ ] Display a "Real-time Telemetry" section with average similarity scores.
- [ ] Provide quick-access links to User Management and Settings.
- [ ] UI must be responsive and follow the established premium design system.

## Dependencies
- **BE-4**: Requires telemetry endpoints for data visualization.
- **SEC-1**: User must be logged in as an admin to view.
