# BO-2: Admin User/Role Management UI

## Description
As an administrator, I want a graphical interface to manage users and roles so that I don't have to use direct API calls for daily operations.

## Acceptance Criteria
- [ ] Implement a searchable and paginated table for Users.
- [ ] Provide a modal or form to create new users.
- [ ] Allow inline role switching for existing users.
- [ ] Implement a separate Role management tab to list and delete roles.
- [ ] UI must show "Last Login" or "Created At" information.

## Dependencies
- **BE-1**: Backend User CRUD endpoints.
- **BE-2**: Backend Role CRUD endpoints.
