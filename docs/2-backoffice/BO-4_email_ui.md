# BO-4: Email Generation & History UI

## Description
As a user, I want a dedicated interface to paste incoming emails and see AI-generated responses in real-time.

## Acceptance Criteria
- [ ] Implement a "New Response" page with a large text area for input.
- [ ] Display the AI response using a streaming effect as tokens arrive via SSE.
- [ ] Implement an "Email History" list showing previous generations.
- [ ] Provide an "Expandable View" to see the full content of past emails and their generated replies.

## Dependencies
- **BE-4**: Backend Email RAG and SSE streaming.
